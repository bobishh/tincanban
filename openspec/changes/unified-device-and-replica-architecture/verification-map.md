# Verification map

Status key: **planned** means no acceptance test for this scenario is authored yet; the named destination is the planned test/case. **existing partial** names nearby code/tests that cover only part of the invariant. **Authored, status unconfirmed** means a focused test exists but no passing result is confirmed. No scenario below is marked complete. Acceptance scenarios are copied in spec order (67 total). Browser scenarios are authored first. The user authorized an intermediate committed CI review on 2026-10-15, including existing browser jobs on separate review branches; this does not close task 12.1 or the final implementation gate. Local browser execution remains deferred.

Final evidence means concrete passing test output and, where required, artifact/provenance records. Passing a nearby test alone does not satisfy a scenario.
